# 均值回归与每 7 天成交约束

2026-09-19 已完成独立的确定性价格策略、CPU 历史回放及复算。使用 $100 虚拟本金，在 55 个已核验 Polymarket 验证合约、13 个宏观事件组上运行。**v2 满足本轮历史期间每 7 天至少一次模拟成交，但主成本情景亏损 9.65%；没有证据支持盈利或升级为默认交易策略。**

这是一层供量化决策使用的价格信号和模拟执行模块。本轮没有调用 Qwen、没有加入新的模型工作流、没有训练，也不代表多 Agent 或 LoRA 的能力改善。原有 Base / Quant / Game Theory 对照及其输出均保留。

## 固定策略

实现：[mean_reversion.py](../src/foretellmesh/mean_reversion.py)。运行配置：[v1](../configs/mean_reversion_weekly_v1.json)、[v2](../configs/mean_reversion_weekly_v2.json)。

- 每小时决策。对之前 72 个整小时分别取该时刻已有、且不超过 3 小时的最新区块均价；至少有 36 个有效点。当前决策报价不进入历史均值。
- `z = (当前 Yes 价 − 历史均值) / max(历史标准差, 0.01)`。这不是统计显著性检验，小时价格可能重复且相关。
- 普通信号要求 `|z| >= 1.5`，Yes 价在 `[0.05, 0.95]`，24 小时变动不超过 0.15；回归目标扣除预计双边滑点及手续费后，每份收益至少 0.01 美元。
- 低于均值买 Yes，高于均值买 No。目标冻结为开仓时的历史均值，**不作为事件最终发生概率**。
- 回到目标、持仓一侧价格较成交参考价下跌 0.05、持有超过 48 小时，或到达预先声明的回放范围末尾，发出平仓指令。止损通过后续成交价执行，不保证恰好以阈值价格成交。
- 普通单预算最多 $2，每日最多两次普通开仓尝试；平仓后同合约冷却 24 小时。同事件组成本敞口最多 $5，总成本敞口最多 $20，挂起买单也占用资金和限额。禁止负现金、卖空、借贷。

## 周频规则及两版差异

按连续时间计算，从账户建立到第一次成交、相邻成交、最后一次成交到回放末尾均检查。每次实际模拟买入或卖出重置计时；提交、取消订单及到期结算不算交易。第 6 天开始寻找补单并按小时重试，预留一天执行时间；所有成本场景分别核验。不足 7 天的末尾区间不要求额外成交；末尾恰满 7 天仍无成交判为失败。

优先普通信号，没有可用普通信号时尝试最多 **$1 的周频参与单**，24 小时后请求退出。`policy_requirements_met` 对必须周频的策略检查实际成交是否达标；成交数据缺失或资金限制不会自动豁免或伪造成交。

- **v1**：补单也要求 Yes 价处于 5%–95%。主成本情景期末 $98.885317，但最长成交空窗 10.7917 天。2025-07-18 至 07-25 的可用报价都在范围外；因此此版未满足用户的周频要求。
- **v2**：只改变周频参与单的价格准入。允许尾部价格，在两侧中选取“每份价格加滑点、再加手续费后小于 $1”的较高价一侧。常规均值回归过滤器保持不变；实际填单时再检查价格和成本。当较高概率一侧不可行时，这可能买到低概率一侧，产生较大相对成本与亏损。预算仍最多 $1，不宣称该单具有正收益优势。

v2 的变化用于处理已观察到的周频准入冲突，没有搜索均值窗口、z 阈值、仓位或持有期来追求盈利。两轮完整配置、特征、账本和结果保留，不能把这两次开发迭代视为独立样本外检验。

## 数据与成交假设

日历为 **2025-02-11 13:30 UTC 至 2025-07-29 18:00 UTC**。55 个合约的准入身份及事件组沿用已冻结验证分区；利用链上历史问题初始化和不可变规则证明，把价格观察扩展到更早的小时。每个合约最多使用到它最后一个已批准观察时点，不使用事后结算时间决定开仓期限。提前扩展的小时是本次研究回放，不新增正式训练样本，不变更原有分区。

来源：`data/processed/pma_macro_research_20260919_v1`、`data/processed/pma_macro_trade_store_20260919_v4`。读入 **623,070 条原生成交，构造 60,554 条截至当时的特征状态**。规则审计文件包含结算元数据，但策略只接收初始化、规则和事先冻结的合约范围；标签分区在配置、特征和代码快照落盘后才解析，只交给结算环境。本轮所有仓位通过模拟卖出退出，没有依靠结算回款结束持仓。最终测试未打开或评分。

每次委托只用决策后 300 秒内**第一个**历史成交区块的均价作为全额成交参考，不跳过不利价格寻找更好的成交。买入价格恶化超过 0.02、优势消失、成本上限被突破或窗口无后续成交则取消。退出也需要后续成交，失败则重试。No 价用 `1 − Yes` 合成；未获得双侧订单簿、深度、队列或真实可成交保证。

| 情景 | 每份买入加价 / 卖出扣价 | 双边手续费（各按成交金额） |
| --- | ---: | ---: |
| 无成本参照 | 0 | 0 |
| 主成本假设 | $0.01 | 1% |
| 成本压力 | $0.03 | 2% |

这些是研究假设，**不是 Polymarket 的实际历史费率或买卖价差**。尾部低价份额下，固定每份加减价可能占很大比例。各情景从头重新决策；成本会改变信号准入和周频买入方向，因此不能把情景差额解释为同一组订单单纯扣除手续费。

## v2 实测

所有账户从 $100 开始。主成本回放：

| 策略 | 期末现金 | 买入 / 卖出成交 | 最长无成交间隔 | 7 天约束 | 采样权益最大回撤 |
| --- | ---: | ---: | ---: | --- | ---: |
| 仅均值回归 | $98.924722 | 21 / 21 | 22.16 天 | 不要求；实测不满足 | 4.67% |
| 仅周频参与 | $90.514557 | 23 / 23 | 6.33 天 | 满足 | 9.49% |
| 均值回归 + 周频 | **$90.345451** | **32 / 32** | **6.96 天** | **满足** | **10.63%** |

主策略已支付显式手续费 $0.962541；滑点加减价计入成交价格、另不重复记作手续费。32 个平仓头寸中 8 个盈利，全部账本现金守恒。损益按入场原因分开：均值回归 **−$1.075278**，周频参与 **−$8.579271**。这些是实际账本归因，不表示移除其中一部分后资金路径必然相同。

| 策略 | 无成本期末 | 主成本期末 | 压力成本期末 |
| --- | ---: | ---: | ---: |
| 仅均值回归 | $100.808433 | $98.924722 | $92.883543 |
| 仅周频参与 | $99.975174 | $90.514557 | $83.716755 |
| 均值回归 + 周频 | $100.827105 | $90.345451 | $81.439992 |

两个要求周频的策略在三种情景均达标。无成本下组合仅赚 $0.83，主成本下亏 $9.65；强制参与成本是本轮的主要损失来源。不能据此推出当前策略可盈利，也不能推出微调能解决执行成本问题。

结果图：[PNG](../runs/pma_mean_reversion_weekly_v2/mean_reversion.png)、[PDF](../runs/pma_mean_reversion_weekly_v2/mean_reversion.pdf)。历史已结算且已通过审计的合约集合有选择偏差；稀疏交易打印不提供完整可交易市场。曲线使用最新已有报价并记录过期标记，是清算价值近似；回撤为采样值，不是真实盘口最大回撤。当前样本不足以证明泛化收益。
