# 多合约输入的显式研究接口

2026-09-21。用户授权扩展一个目标同时参考多个合约的关系表达。实现 `team_multi_input.py`，作为 `executable_multi_input_v1` 可选协议接入已有冻结团队、明确任务交接、失败反馈和原始调用复算流程。旧的单 peer 协议保持原样，旧实验通过各自源码重放。

## 变量与预测分开声明

新的研究结构保留假设、预测类型和跨度，但取消含糊的 `target/peer` 变量角色和重复的合约对绑定：

- 每个变量声明 `variable_id`、`market_id`、`definition`、`quantity`、`unit`、`lag_days`。
- 每个预测声明唯一 `target` 和非空 `input_ids`。多个变量共同服务一个目标；变量也可以被不同目标共享。
- 一个关系最多八个变量、四个预测目标。全部变量必须使用，全部引用必须存在，同一测量不能靠换变量名重复声明。
- 合约编号只能来自已准入目录。变量合约与预测目标的并集必须等于本轮明确任务的编号集合。可以弃权，不能暗中换目标。

因此一个目标可同时使用自己的历史价格、第二个合约的价格和第三个合约的滞后价格，而不再因重复 target 被拒绝。这只是接口能力示例，不是程序替团队指定的策略。

数据角色逐项绑定变量编号与已登记来源。来源仍仅有经过文件哈希绑定的历史 Yes 成交价格；事件票房、股票价格、运动结果等新测量没有因此自动出现。来源数量类型与单位必须匹配，缺失保留为缺失；不把事件数据替换成合约价格。`market_id` 的声明和来源字段校验并不能证明任意自然语言描述真实，或证明该测量支持研究假设。

## 计算与评分

Quant 对每个目标输出一个表达式，使用 `v('variable_id')` 读取事先声明的量。表达式必须使用该目标全部且仅有的输入，不能改合约、单位、滞后、目标或变量集合。解析器仅允许受限算术、`abs/min/max` 和变量读取；不执行生成的 Python。内部将变量引用降为已有安全算术解释器的值槽，不把槽编号误当成实际滞后。

变量读取分别检查该合约初始化时间、观察时点减去滞后、成交来源时间和三小时新鲜度。任何缺失、未来来源、除零或输出越界都失败，没有补值或隐式截断。即使直接调用预测函数，缺失来源也不能绕过校验。

计划包含完整关系、来源映射和计算表达式，**冻结后才读取未来目标进行评分**。继续沿用本轮对照的初始化后前九十天 UTC 午夜网格、按预测跨度分隔的非重叠窗口；前一轮的成交时点覆盖诊断未混入此次评分。

- 每个 `(target, observation_time)` 至多一份预测；增加输入不增加样本数。
- 事件结算目标每个 target 只计一次，标签必须在反馈截止前可用。
- 同事件组的合约先在组内汇总，再按组平均；多个同行输入不增加独立目标事件组数量。
- 仍要求至少三个目标事件组、80% 有效覆盖及最低观测数。单目标关系可以进行计算诊断，但不能单凭它通过独立验证候选筛选。
- 未来价格误差与事件 Brier 分开，不等于扣费交易收益。合成数据上通过机制测试不能宣称真实预测能力提高。

## 字段澄清后的真实结果

第二版单次检查完成四次冻结模型调用，约 36 秒模型生成时间，四次输出均通过各自结构校验。研究员成功提交一个目标、三个显式绑定变量：足球合约 `248881` 的 `win_probability/%`，两部电影合约 `251132`、`251306` 的 `revenue/$`，共同预测合约 `252406` 的七天后 Yes 价格。多输入结构已在真实模型调用中通过，旧的“重复 target”限制不再阻止这一表达。

数据角色把三项来源全部明确标为缺失，逐项说明已登记来源没有匹配量／单位，没有用历史 Yes 成交价替换外部概率或票房数据。工作流状态为 `unavailable_variables`，未进入价格覆盖、计算、冻结计划或预测评分。一次机制检查通过，仍不是有效策略。

人工核对实际规则后，研究内容还存在明显未衔接之处：假设叙述的是体育周边商品成功与球队比赛表现的关系，但唯一预测目标 `252406` 是“Bitboy 在 10 月 14 日前宣布离婚”，输入则是球队胜率和两部电影票房。输出没有解释这些变量如何共同预测选中的目标，票房也不是已声明的球队周边销售量。**这不证明跨题材潜在关系不存在；它说明本次声明没有把假设、变量和目标连成一项自洽、可验证的研究。** 不能把这个例子单纯归因为缺数据，进而盲目补充票房或胜率。

复盘中的三条数据请求仍用合约初始化时间充当“历史时间要求”，不能当作变量的真实发布时间。胜率的含义与其独立来源也未确定，不能把结算标签或当前市场价格当作历史真实概率答案。复盘生成的下一项任务已归档，因单次检查预算结束而未执行。
