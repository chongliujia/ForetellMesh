# 研究语义一致性诊断 v1

本轮在多合约研究与数据选择之间增加暂定语义检查。目标是检查团队是否确实说清“用哪些量、预测哪个目标”，不检验统计关系是否成立，也不按题材限制团队探索。

## 协议

- 使用同一冻结 Qwen3-8B-Base，模型 revision、种子、数据目录和评分时钟沿用已有协议；只读取已准入的 22 个训练合约。
- 每个预测目标分别审核，输入为假设、目标历史规则及其全部变量的定义、量纲、单位、滞后和原合约规则。审核角色看不到结果标签、历史价格、数据可用性或测试预期答案。
- 要求覆盖目标和每个变量；判断为 `aligned`、`mismatch` 或 `uncertain`。`aligned` 仅表示声明初步对应，并不验证因果关系或预测效果。
- 明确提出可检验联系的跨题材研究允许通过；题材不同或暂时缺数据本身不能成为否决理由。审核不得替研究者编造未声明的联系。
- 模型首次提案后，最多进行一次实质性语义修订，再审核一次；格式修复仍沿用每次角色调用最多一次的原限制。修订只能针对本次已接受提案；不得以改写文字获得另一项重复实验的评分机会。
- 尚未澄清、审核格式失败、主动放弃或审核器未通过固定检查时，暂停数据选择、价格读取、计算和结果标签读取。失败及修订全文保留，具体反馈交给学习角色。

## 审核器本身的检查

先登记三个固定案例，再生成两轮新研究。预期答案保存在实验注册输入中，仅程序比较，不提供给模型。

1. 上一轮真实输出：假设谈球队表现与周边销售，变量却包括电影票房，预测目标实际绑定离婚合约。预期需要修订；原始 run 和 artifact hash 必须匹配。
2. 同一合约当前 Yes 成交价对其七天后 Yes 成交价的延续性参照，预期声明一致。
3. 显式测试另一合约滞后一天的 Yes 成交价是否为目标七天后价格提供额外信息，预期声明一致。此例防止审核器直接拒绝跨题材研究。

后两个是人工固定的机制对照，不是团队发现的策略，也不进入研究角色上下文、评分、交易或训练监督。三个案例全部匹配且审核输出完整，才允许本轮新研究通过语义关卡。三个案例不能建立一般语义准确率，更不能证明同一 Base 审核角色独立可靠。

## 实现与复现

代码：`team_semantic_consistency.py`；通过 `executable_semantic_consistency_v1` 显式启用。旧协议默认行为和历史文件保留。注册输入包含案例，调用日志包含案例审核与新研究的完整顺序；CPU 复算重放两部分并核对哈希及冻结顺序。

```bash
PYTHONPATH=src python -m foretellmesh.team_research_loop preflight --config configs/team_semantic_consistency_v1.json
PYTHONPATH=src python -m foretellmesh.team_research_loop run --config configs/team_semantic_consistency_v1.json --output runs/qwen3_8b_team_semantic_consistency_v1
PYTHONPATH=runs/qwen3_8b_team_semantic_consistency_v1/source_snapshot python -m foretellmesh.team_research_loop audit --output runs/qwen3_8b_team_semantic_consistency_v1
```

测试覆盖审核字段和完整变量覆盖、失败时禁止价格／标签访问、一次修订限制、跨轮重复禁止、控制案例答案不泄露、未合格审核器关闭后续环节、实际归档来源哈希验证，以及原始调用的逐次复算。

审核角色识别了原始错配，并接受两个明确声明的对照，包括跨题材价格关联。不过原始错配理由里仍出现“题材不相关”的措辞：本轮正例表明它未一概禁止跨题材关系，却不能据此排除这种偏见或证明语义可靠性。

两轮新任务都分配四个合约（248881、251132、251306、252406），研究者只使用前三个，遗漏 252406；原回复及一次格式／任务修复都未消除错误。学习角色正确接收具体错误，第二轮直接执行其下一任务，但该任务仍保留同样的四个合约和相同目标。故两轮都在语义节点之前终止，**本轮没有真实新提案完成“语义反馈→作者修订→再审”的模型闭环**；这条分支目前只有机制测试和精确回放验证，不能报告为已证实团队自主改进。

本轮支持的结论是：已知错配可以被本次审核识别，且确定性流程能阻止未通过检查的研究继续；团队的任务选择与错误修订仍不稳定。尚不能从这些结果断定总体数据规模不足、PPO 不适用或应该微调模型。

建议下一项独立、限额实验检查任务协商：由研究者明确指出无法使用的合约及原因，并向协调角色提出修改任务，保留原任务和修改记录；程序不静默删除合约，也不强迫研究者为凑齐 ID 编造关系。先验证反馈是否真的改变后续行动，再考虑针对明确变量补历史数据。本轮不自动启动这一后续实验。

模型及适配器冻结，未微调、未打开新开发集或最终测试，未评价收益，也未晋升策略。
