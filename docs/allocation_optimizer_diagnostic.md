## 本次重新计算的事实

来源为冻结的 `pma_allocation_multi_agent_v1`。诊断仅读取该训练实验的日志、主成本决策与账本，以及原始 Agent 输入/输出；检查所有实际消费的冻结文件哈希，并校验退出盈亏之和与原报告一致。

### 高等待率不等于学会选择空仓

每条轨迹有 4,681 个决策点。下表的“主动等待率”只在至少有一个合法非等待动作的时点计算；它包括持仓时选择继续持有，不等于现金空仓率，也不是相同状态上的反事实比较。

| 多 Agent 种子 | 仅等待合法的时点 | 有买卖可选的时点 | 主动等待次数 / 比例 | 买入成交 | 平均完整持仓小时 |
|---|---:|---:|---:|---:|---:|
| 7 | 1,813 | 2,868 | 2,626 / 91.56% | 86 | 45.06 |
| 17 | 3,992 | 689 | 8 / 1.16% | 160 | 5.15 |
| 27 | 4,003 | 678 | 3 / 0.44% | 143 | 7.13 |

种子 17 和 27 的损失主要出现在策略主动退出的成交：分别为 −$10.681654 和 −$8.581442。种子 7 没有主动卖出动作，退出来自持仓上限或止损，分别贡献 −$2.434029 和 −$3.429019。此为账本归类，**不能推断取消止损、延长持仓一定改善收益**。

主成本下三个多 Agent 策略分别发出 242 / 351 / 347 次买单，其中满足现有均值回归净价差阈值的只有 18 / 24 / 9 次；81 / 108 / 116 次买单没有历史均值。PPO 没有被要求只按均值回归交易，这也不是“其余订单必然错误”的证明。统计包含未成交订单；均值价格目标不是结算概率，也不是经验证的期望收益。

### 优化器还没有充分排查

- 每策略 32,768 步，32 个 rollout，7 遍完整历史，且反复使用相同的 6 个事件组。七遍不是七份独立数据。
- 费用按完整周期轮换，主成本只有三个完整训练周期；训练中的随机策略收益不能替代冻结 checkpoint 的评估。
- 25 个平铺动作中只有一个等待；在无持仓且四个候选均可买入时，有 16 个买入动作，均匀探索给等待的概率仅为 1/17。这是编码性质，**不是已测得的 PPO 动作概率**。改用 DQN 但仍均匀探索合法动作也会遇到这一问题。
- `gamma=1` 保留期末净权益目标；`gae_lambda=0.95` 时，48 小时后的 TD 残差对当前 GAE 的直接系数约为 0.0853。critic 仍能传递更长期价值，不能把它说成只有 20 小时记忆；延长信用分配需要实验验证。[GAE 原论文](https://arxiv.org/abs/1506.02438)
- 最终 optimizer 记录的 explained variance 约为 0.88–0.95，但各策略 31 条 CSV 中有 10–20 条为负。该指标依赖当前批次，不证明收敛或盈利。CSV 在更新前写出，最后一行落后于训练报告中的最终更新，二者不可混作同一时点。
- 已有平价正成本合成检查中，六个策略学会零交易；它证明简单情景可学，不证明真实时序中的探索与信用分配已解决。

### 输入信息的实际限制

84 次工作流中，35 次没有外部证据、49 次各有一条外部证据，合计只有 6 个不同外部证据 ID。这里把确定性市场特征与外部发布分开计数；没有外部证据不等于没有价格信息。

外部证据距观察时点的年龄为 0.21–44.21 天，中位数 20.73 天（按出现次数计算）。79 个有效 Forecast 与市场价的最大差仍只有 0.0000046501。证据经过时间校验，但覆盖有限。强化学习可以改进交易选择，无法凭空增加独立信息；增加经验回放次数也不增加宏观事件数量。

因此，当前首先需要解决的是**把已有历史库转成更广的可用训练集**，不能据此直接判断必须再下载大量价格数据。缩小来自此前选定的美国宏观试跑范围、规则/身份/结算补证、历史时点价格覆盖、事件去重及已冻结的保留用途；未进入这 25 个训练合约的市场并非都不可用。

下一步数据工作应先盘点已有 779 个价格覆盖市场的事件分组与用途，优先找未被保留的早期事件，逐项补齐准入缺口；不足时再扩展全库检索。旧 validation/test 不回收为训练。研究新闻/发布与盘口深度并未因下载成交日志而自动齐备：价格分配策略可先利用合格价格历史，Agent 信息增益需另补严格事前证据，执行模型的成交量与价差假设仍须明确。

工作优先级调整为：现有数据的训练准入扩展优先；PPO / Double DQN 保留为有限的机制对照，不在六个事件上开展大规模算法搜索。下面的 18 任务方案为候选比较设计，不代表已启动或必须立即跑完整网格。若扩充了训练数据，须先冻结新的数据版本，再让所有算法使用相同版本进行比较。

## 方法优先级

| 方法 | 本项目适配性 | 建议 |
|---|---|---|
| Maskable PPO | 已接入离散动作与风险掩码；训练预算与探索尚未充分诊断 | 保留基线，先做更长预算和单独的熵系数对照 |
| Masked Double DQN | 对应现有离散动作；经验回放可重复利用模拟转移；Double Q 缓解最大值选择的高估 | 第一个新增算法对照 |
| Masked QR-DQN | 估计回报分布，可补充尾部诊断 | 第二阶段；分布估计不等于已校准风险，先按均值保持相同净权益目标 |
| Recurrent PPO | 若历史摘要丢失重要状态，记忆可能有帮助 | 状态诊断后再做；现有 MaskablePPO 不支持循环策略，不能直接换成 LSTM 而丢掉动作约束 |
| SAC / TD3 | 当前动作是离散的市场、方向和 $1/$2 金额 | 连续仓位接口确有必要时再评估；SB3 SAC 不能直接使用当前 Discrete 动作，另有离散 SAC 变体 |
| CQL / IQL | 适用于只从固定行为转移数据学习的 offline RL | 当前可与历史模拟器交互，暂非首选；有限行为覆盖与模拟成交误差不会被自动解决 |

依据：[PPO 原论文](https://arxiv.org/abs/1707.06347)、[Double DQN 原论文](https://arxiv.org/abs/1509.06461)、[QR-DQN 原论文](https://arxiv.org/abs/1710.10044)、[MaskablePPO 2.7.1](https://sb3-contrib.readthedocs.io/en/v2.7.1/modules/ppo_mask.html)、[SAC 2.7.1 动作支持](https://stable-baselines3.readthedocs.io/en/v2.7.1/modules/sac.html)、[CQL 原论文](https://arxiv.org/abs/2006.04779)、[IQL 原论文](https://arxiv.org/abs/2110.06169)。优先级是结合本仓库接口与诊断的判断，论文没有证明这些算法能让本项目盈利。

工程注意：[SB3 2.7.1 的 DQN](https://stable-baselines3.readthedocs.io/en/v2.7.1/modules/dqn.html) 是 vanilla DQN，不能直接标成 Double DQN；[QR-DQN 2.7.1 源码](https://sb3-contrib.readthedocs.io/en/v2.7.1/_modules/sb3_contrib/qrdqn/qrdqn.html) 的下一状态最大值计算也未接入本项目掩码。探索、贪心决策、replay buffer 的下一状态动作掩码和 bootstrap 全部需要一致处理。终态不 bootstrap；等待始终合法。不能仅在执行器把非法动作改成等待后宣称完成了 masked Q-learning。

GRPO 是本项目未来预测模型训练的可选方向；本轮是在冻结语言模型后优化多步资金分配，不把 GRPO 作为 PPO 分配器的直接替换。也不因有多个语言角色就立即引入多智能体 RL：当前角色提供冻结特征，只有一个账户策略在学习。

## 下一轮建议协议（设计，尚未执行）

1. 先给新 Q-learning 实现加入确定性验证：非法下一动作具有极高 Q 值时仍不得进入 target；Double Q 必须由 online 网络选动作、target 网络估值；终态目标只有即时奖励；保存/加载、费用、未来信息修改和等待合法性保持一致。合成学习任务同时覆盖无优势空仓与可观察、扣费后有优势的延迟回报，防止“永远不交易”成为唯一通过方式。
2. 冻结三组：原设置 PPO、更低探索压力的 PPO（仅将 `ent_coef` 从 0.01 改为 0）、Masked Double DQN。每组保留 `price_control` / `multi_agent` 两种输入，种子 7 / 17 / 27，共 18 个训练任务。保留 32,768 与 131,072 步检查点；全部训练和冻结后才评估，不按中间收益早停或选最佳点。DQN 具体参数须在上述合成检查后、真实训练前另存可执行配置，当前文档不是可执行实验配置。
3. 保持相同候选排序、25 个动作、训练事件、费用轮换、现金/仓位限制、订单生命周期、最大持仓和奖励。首轮不同时改成分层动作，不提高风险上限，不增加活动惩罚；否则无法分辨算法变化的贡献。PPO 内的 GAE 对照单独留作后续，不与熵/预算改动打包。
4. 同时报告环境步数、optimizer 梯度更新数、采样批量、参数量、CPU 时间与内存；相同环境步数并不代表相同计算预算。比较配对种子差值和全部结果，不只挑最好的种子。
5. 评估沿用六种成本、$100 现金和固定均值回归对照，报告净期末权益、回撤、主动等待率、买卖次数、手续费、加减价损耗、原始成交价格盈亏、退出原因和取消率。零成本检查仅作归因，不代替扣费结果。
6. 本阶段只使用已准入训练分区，结果标为适应性训练内方法诊断。旧 validation 已反复观察，不作为新方法的未见泛化证据；final test 继续封存。冻结方案后，另准备未参与调参的新事件作前瞻或时间推进评估。

如果加长预算后的 PPO 与 Double DQN 都只能达到现金，应先扩充事前信息和独立事件。若新算法在有优势合成任务明显更可靠、历史训练也有一致改善，才值得推进新的开发数据评估；不能据此直接晋级或宣称样本外盈利。
