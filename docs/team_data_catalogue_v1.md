# 团队可查询数据目录 v1

本轮让团队在选择或协商任务、提出变量之前，主动查询现有数据能测什么。模型仍自主选择合约和假设，程序不规定关联类型或交易策略。外部测量可以保留为待补来源，但不能为了匹配现有数据而把票房、比赛结果改叫价格。

## 查询边界

`research_data_catalogue` 每轮发起一次结构化查询：`source_ids`、`market_ids`、`as_of`、`reason`。来源必须在程序注册目录中，合约必须在已准入训练目录中，最多各四个且不得重复；查询截止时间不能晚于研究截止时间，合约须已初始化。每次模型调用最多一次格式修复，查询失败消耗本轮预算，不静默跳过。

返回内容包括精确数量名称、单位、测量含义、数据 artifact 哈希、时间字段，以及所选合约在查询截止时间之前的记录数量和首末时间。只统计初始化之后、截止时间之前的记录。查询不返回价格值、价格统计、结算结果、预测分数或策略建议。它不读取标签对象。

当前唯一注册来源为历史 Yes 成交价格：`contract_yes_trade_price`，单位 `USD_per_YES_share`，按交易区块聚合。它不是事件真实概率、外部收入数据，也不是可执行订单簿报价。目录只描述当前注册的来源，不宣称仓库或现实世界不存在其他可补充证据。

研究者、任务评估者、协调角色及学习角色接收目录查询结果。研究提示明确允许基于已知测量提出**新**假设，并要求新假设与原始外部测量假设区别记录；仍可请求缺失外部来源或放弃。来源菜单由程序提供，模型不能添加虚构来源。后续来源角色依旧独立核验每个变量的数量、单位及绑定。

目录覆盖是**离线训练研究的设计元数据**，不被回填为更早历史预测的输入。单合约有记录不代表多个合约有共同可用样本、未来目标可用或能够成交；这些仍按已有因果读取、陈旧时间、预测期限及冻结评分流程核验。源时间是历史交易时间；合约初始化不是外部测量的发布日期。

## 版本与实验

显式模式：`executable_data_catalogue_v1`，配置 `configs/team_data_catalogue_v1.json`。相比审核权限边界 v1，仅新增设计前目录查询及对应指导；同一冻结 Base、原失败任务起点、两轮预算、22 个训练合约、原数据及评分时钟。模型审核继续仅供参考，确定性检查保持否决权。没有训练模型、增补外部数据或打开保留集。

旧模式继续隐藏初始研究阶段的来源信息，历史实验保留原始行为。本轮新模式修改数据可见性，不应把新旧结果差异解释成参数学习。

```bash
PYTHONPATH=src python -m foretellmesh.team_research_loop preflight --config configs/team_data_catalogue_v1.json
PYTHONPATH=src python -m foretellmesh.team_research_loop run --config configs/team_data_catalogue_v1.json --output runs/qwen3_8b_team_data_catalogue_v1
PYTHONPATH=runs/qwen3_8b_team_data_catalogue_v1/source_snapshot python -m foretellmesh.team_research_loop audit --output runs/qwen3_8b_team_data_catalogue_v1
```

223 项回归测试通过。新增测试覆盖：初始化和查询截止时间过滤、添加未来记录或改变价格值不影响元数据结果、空覆盖显式报告、禁止未知合约／来源／未来截止时间、查询先于研究、查询结果送达团队、失败查询消耗预算、旧模式来源可见性保持，以及完整流程和调用记录精确复算。

## 下一步判断

目录已可查，眼前的阻塞仍是任务状态与历史记录混淆。历史反馈包含原始失败 JSON，第二轮逐字重复旧评估，提示应检查这类历史原文是否干扰当前任务；仅凭本次观察尚不能确证因果。

建议下一轮做固定输入的上下文对照：保持模型、当前任务和目录一致，比较“原完整失败上下文”与“仅保留结构化错误、失败实验指纹和当前任务”的执行结果。完整历史仍保存在审计文件，不能丢弃失败或反复抽样只保留成功。该对照不改变来源或评分规则，也不自动触发微调。
