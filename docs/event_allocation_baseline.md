# 数天至数周的事件持仓基线

2026-09-20。按用户明确的交易频率方向完成 v2：普通交易复核每 3 天一次，小时检查用于风险和执行，首次有效研究或概率变化至少 5 个百分点时可额外复核。复核不意味着交易；没有成本后优势时继续持有现金。

已完成固定规则模拟，没有新增 RL 训练、Qwen / LoRA 更新或 LLM 调用。最终测试继续封存。低频机制有效，但当前信号下尚未盈利，不晋级默认策略。

## 主成本实测

初始虚拟资金 $100。成本假设为买入每份加 $0.01、卖出每份减 $0.01，买卖各收取成交金额的 1%；结算赔付费率显式假定为 0。这些不是已经校准的历史真实盘口或收费规则。

| 方案 | 期末资金 | 买入 / 卖出 / 结算 | 平均持仓 | 最长持仓 | 手续费 |
|---|---:|---:|---:|---:|---:|
| Agent 事件持仓 | $90.55 | 14 / 13 / 1 | 7.21 天 | 30.95 天 | $0.44 |
| 相同信号、48 小时退出请求对照 | $96.16 | 16 / 16 / 0 | 1.73 天 | 2.36 天 | $0.60 |
| 历史市场价格参考、事件持仓 | $90.55 | 14 / 13 / 1 | 7.21 天 | 30.95 天 | $0.44 |
| 旧均值回归控制 | $85.91 | 62 / 62 / 0 | 原协议 | 原协议 | $2.32 |
| 持有现金 | $100.00 | 0 / 0 / 0 | — | — | $0.00 |

事件持仓组合的相邻买入成交间隔中位数约 **7.00 天**。这是该轨迹的实测结果，不是强制周频；不同市场可以在相近时刻建仓。单个市场再次建仓的间隔为约 7–46 天。最长持仓超过四周，研究观察截止、预测过期或 48 小时到来都不再自动触发事件策略卖出。

48 小时对照到时只提交退出请求，仍需新鲜报价和之后的实际成交参考；不能假设一定在第 48 小时成交，所以实际最长约 56.65 小时。

事件持仓的小时与事件采样最大回撤约 **9.58%**，48 小时对照约 **4.12%**。旧均值回归约 14.59%，但它使用不同的入场规则及旧研究边界；与它比较不能把全部收益差归因于降低频率。严格的持仓时长对照是前两行，其余信息、开仓判断和风险规则相同。

主成本下 13 次卖出全部来自保留的价格止损，1 笔持有至结算。按相同成交时间和数量拆分：原始价格损益 **−$7.118843**，买卖加减价损耗 **$1.891579**，手续费 **$0.440541**，合计净损益 **−$9.450963**。这轮亏损主要已不是频繁支付手续费，而是所选持仓的价格／结算表现欠佳；不能据此认定删除止损就会盈利。

## 冻结协议与信息覆盖

配置：[event_allocation_baseline_v2.json](../configs/event_allocation_baseline_v2.json)。

- 每 72 小时常规复核一次；首次有效研究或与上次已处理研究相差至少 0.05 时可额外复核。刷新了研究但观点几乎不变，不会自动触发交易。
- 已有研究每周刷新、有效期 7 天。实际生成及排队延迟完整保留；过期和失败保持缺失。它们阻止新的信号交易，但不自行制造平仓请求。预测缺失时仍持续检查价格风险。
- 开仓要求 `max(0, 事件概率−0.02)−含费买入单价 >= 0.03`；No 侧使用互补概率。0.02 是本轮固定敏感性保护，不是已测得的置信区间。
- 普通退出比较乐观持有价值 `min(1, 事件概率+0.02)` 与当前扣费卖出所得；剩余差不超过 0.005 时可请求退出。计算不重复扣除已经付出的建仓费用。风险退出优先处理。
- 保留现金／事件／组合／仓位风险上限、每笔最多 $2、价格下降 0.05 的止损、退出后一天冷却和每日最多两次买入尝试。无最低交易频率、无持仓时间奖励、无无条件最低持仓时间。
- 事件策略没有强制的 48 小时持仓上限；只有对照组保留该退出请求条件。
- 不使用后来修订的观点，不回填失败预测，不用历史价格均值冒充结算概率。

本轮准入范围是训练集 37 个合约、12 个事件。复用的真实多 Agent 输出为 84 份任务、79 份有效，覆盖 17 个合约、6 个事件。其余 20 个合约没有有效输出，保持缺失；因此不能声称验证了 12 个事件上的研究能力。新增事件未强行填入合成预测。

市场参考对照使用相同信号的观察时间、实际可用时间、失效时间和失败掩码，只把 Agent 概率换成分析当时的市场价格。这一对照在主成本下与 Agent 结果一致，进一步说明当前输出未建立独立研究优势；它也不是当时未知的真实概率。

### 主成本入场诊断

将 `replays/cost_assumption/agent_event.ledger.jsonl` 中的 14 笔 `buy_fill` 按 `signal_id` 与 `signals.jsonl` 的 `sample_id` 连接：入场所用 Agent 概率与研究观察时市场价格的最大绝对差仅为 `1.4777792556319724e-7`。成交时研究年龄最短 1.04 天、中位 3.04 天、最长 6.14 天；所买方向的预测概率减去当前原始成交参考价格，最小 0.07、中位约 0.0924、最大约 0.1847。

因此，这些入场的表面优势几乎全部来自价格相对旧市场参考的移动，而非 Agent 提供的独立概率修正。其行为近似以数日前市场价格为锚的反向交易；现有证据不能证明价格应当回到旧值，也不能判断价格变化是否反映新增事件信息。13 次卖出全部触发止损与这种信号缺陷一致，但不能单独证明止损规则导致亏损，或延长持仓／取消止损能够盈利。本轮是固定规则基线，没有 PPO 训练或 PPO 决策，不能将本轮亏损归因于 PPO 优化失败。

v1 在用户进一步明确“数天／数周”节奏前已经启动，仍允许每小时普通复核；其配置与完整输出保留于 `runs/pma_event_allocation_baseline_v1/`。v2 是对此次明确方向的修正，未依据 v1 收益搜索阈值；本页的正式复算和机制核验均指 v2。

## 研究、执行和结算边界

新执行器仅从市场目录取得身份、事件组和初始化时间，不将旧 `retire_at` 作为卖出时间。研究输入及信号保持原截止，不生成截止后的虚构研究。

价格回放使用相同训练市场 ID，覆盖至预先固定的 2025-01-01 行政截止，含 562,324 条原生成交。实际结算标签和时间只由执行器在到时后处理，既不作为决策输入，也不用于提前安排获利买卖。全部持仓在真实已核验的结算事件或有效卖出后完成记账。

订单只能参考决定后、1 小时有效期内的首个成交；不寻找之后更有利的价格。买入订单在成交时重新检查信号是否仍有效、是否被新输出替代，以及成本后优势。缺少成交则撤单。入场费用不重复收取，结算不伪装成卖出成交。

每小时和账户事件采样清算权益，显式记录报价过期。采样回撤不是完整逐成交或订单簿回撤；成交记录也不能证明可执行深度、排队位置和真实成交量。
