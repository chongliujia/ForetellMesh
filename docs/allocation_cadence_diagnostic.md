# 训练分区的成交机会与周频失败诊断

2026-09-20 已完成。**现有回放的主要限制包括短成交窗口、陈旧报价和准入范围空档；同时确实存在选单遗漏。只增加周频惩罚不足以证明能解决这些问题。** 本轮只回放已有冻结策略，没有更新权重，没有读取验证或最终测试分区的输入、标签。

后续已完成[订单有效期与挂单生命周期核验](allocation_execution_lifetime.md)：1 小时和 4 小时下，冻结 PPO 在训练回放中满足周频，但费用后的损失明显扩大；下文保留原 300 秒诊断。

## 关键发现

主种子在“距上次成交已满 6 天”的阶段共有 634 个决策点：

| 该时点的情况 | 决策点数 |
| --- | ---: |
| 存在合法动作，但全部缺少可接受的后续成交参考 | 487 |
| 没有合法动作，也没有自动退出请求 | 110 |
| 已选动作或自动退出有可接受参考 | 15 |
| 槽位内另一个动作有可接受参考 | 19 |
| 只有被四槽位截断的候选有可接受参考 | 3 |

前两项合计 **597 / 634，约 94.16%**。这只描述已经走过的账户路径及其逐时决策点，不证明所有其他持仓路径都不可行。

- **成交窗口是明显限制。** 当前每小时决策一次，只接受决策后 300 秒内的第一笔原生成交；无参考就撤销。主种子总计发出 1,268 个订单，其中 1,171 个因缺少这个窗口内的成交参考而取消，另 1 个因价格限制取消。不能将此解释成 Polymarket 整体没有流动性，也不能直接把窗口外成交补记成已成交。
- **准入与报价也会阻止动作。** 上述 110 个无动作时点中，51 个没有处于当前准入范围内的市场；35 个没有 ready 报价；24 个已有 ready 报价但仍被现有规则限制。门槛统计按动作计数、可能重叠，不能把各条拒绝原因相加作为独立失败次数。
- **等到第 6 天才尝试，有时已经太晚。** 主种子 8 段超期中，有 5 段在截止前 24 小时的逐时决策点上，即使查看全部合法候选及自动退出，也没有能够在原 300 秒窗口内、且在截止前到达的可接受成交参考。另 3 段至少存在一个未选中的可用参考。其他两个种子也各有 5 段这样的“预警期无参考”区间。
- **选单与候选截断有改善空间。** 例如 2024-08-12 03:00 UTC，主种子距离期限只剩 285 秒；槽位外合约 `504492` 的 No 侧在 179 秒后有符合原执行条件的成交参考。该事实仅供事后诊断，不能据此把未来成交时间加进当时的排序，也不能用这个单例声称全程可行。

“可接受参考”是沿用当前模拟器规则的条件判断：第一笔后续成交、原价格限制、非正卖价取消及结算先于成交的处理。它不证明真实盘口能全额成交，也没有补齐历史买卖价差、深度或队列。

## 时间边界与诊断隔离

每个决策先用原始观测与动作屏蔽选定动作，然后生成诊断。输出分成 `causal` 与 `retrospective` 两部分；后一部分不会交给策略。每次检查观测哈希、动作屏蔽和所有可见合法动作的一致性，保证诊断没有改变政策输入。未来参考不能参与资金分配或候选排序。

`causal` 表示截至本次实验决策时的账户状态、历史价格及预先固定的实验范围，并不意味着其中所有范围信息都是历史公开市场事实：

- `initialized_at` 来自历史链上初始化记录。
- `retire_at` 来自**最后一个准入观察点**，不是已证明的公开合约到期时间。
- 策略观测中的 `hours_to_retire` 和 `hours_to_end` 包含这些人工实验边界。现有回放只证明在此固定实验协议下的行为；正式部署前需要替换或移除没有历史公开依据的市场截止特征，再让所有对照共用新环境。

分区读取只允许 `train`。可以读取已冻结的分组元数据检查隔离；不解析验证或最终测试输入、标签。结算只进入模拟器的账本，不能作为模型输入。所有不利区间保留，包括回放开局和结束边界，不通过缩短回放范围或删除无成交时段改善周频结果。

## 后续顺序

原 [RL 设计稿](allocation_rl_design.md) 中“只改变超期惩罚”的实验仍未启动。根据本轮训练侧诊断，先核验共同执行环境，再冻结用于奖励对照的环境版本：

1. 明确订单有效期与跨决策时点的存续、撤单、资金占用和成交处理。若比较其他有效期，先声明时长、价格限制与成本，用同一环境重跑固定规则和 PPO；始终取合规的第一笔参考，不能跳过不利价格寻找有利成交。
2. 补充独立训练事件和连续可用的历史交易/报价覆盖，保留无覆盖时段。检查人工范围结束时间的使用，防止把实验信息当作真实市场知识。
3. 执行协议确定后再加入单一超期惩罚，按原计划进行配对种子实验。新开发清单仍未冻结，最终测试继续封存。

以上是基于训练诊断的后续工作顺序，不是已实施的执行改动。本轮未更改 300 秒窗口、候选槽位、资金上限或默认策略，也未自动选择新惩罚权重。
