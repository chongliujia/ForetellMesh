# 冻结团队的自主检索与连续账户探索

本文保存 v2 历史结果；后续接口修正和数据扩容见 [扩展实验](team_discovery_expansion_v1.md)。

用户确认的阶段目标：一个 **100 美元虚拟账户，成本后达到 110 美元，累计收益 10%**。没有指定月度、年度或强制达标期限。研究预算和历史回放范围仍须事先冻结，不能反复调参直到达标。达到阶段目标本身不证明方法可复现，也不自动触发微调。

## 实测结果

固定批次已完成并通过冻结源码重放：14 个回合、84 次模型调用，全部权重冻结。执行 26 次有效目录查询，检索覆盖 8 个合格学习合约；形成 8 项调查，其中 3 项跨合约。14 个回合均生成非空、引用实际反馈字段的候选复盘，但没有独立验证其文本结论。

6 / 14 个回合形成完整决策。另 8 个回合的单合约方向字段不符合本版研究工具契约，修复上限后仍失败；没有补造概率或成交。3 项跨合约调查的同期日变化配对数都为 0，8 项调查均被 Critic 标为数据不足。检索范围确已扩展，但没有证明发现有效关系。

同一个账户完成 1 次模拟成交，费用 $0.019801（已计入损益），最终现金 **$98.000001，累计约 −2%**，离 $110 还差约 $12；离散标记价格最大回撤约 $2。未达到 10% 目标，没有微调或候选推广。

预测覆盖为 7 / 15 个目标观察；仅在这 7 个共同覆盖目标上，模型 Brier 为 0.169884、同期市场为 0.220775。由于失败造成缺失，且全批次均为学习分区，不能据此宣称方法有效或泛化改善，也不能与全部 15 个市场目标的分数直接比较。

64 项相关测试通过；14 个回合的原始请求、搜索、工具、反馈、时点账户快照和最终连续账本重放一致。见运行目录 `report.json`、`audit.json`、`portfolio.json`、`research_records.jsonl` 和 `diagnostics.json`。接下来需要补足同期可比较数据、改进研究计划与工具协议的一致性，再冻结候选方法做独立检验；不能以本轮结果触发微调。

## 本轮实现

- `team_discovery.py`：团队先自行选择两次目录查询，每次可以关键词搜索、精确 ID 检索或空查询分页浏览；第二次看到第一次的结果后再决定。目录按观察时间过滤后才计算匹配和排名，没有人工金融行业关系表。
- 合格目录仅由 `train.jobs.jsonl` 中的历史规则和初始化证明生成，去掉结果标签、未来结算时间和事后统计，不打开开发或最终测试输入。当前小样本目录有 8 个合约；14 个观察点的可见数量由 1 个增至 8 个。该接口能扩展，但目前不等于检索全部 128 个原始候选。
- 团队可从目标合约和实际检索结果中选择至多两项研究，自己决定对象和 1–30 天窗口；在工具执行前保存假设、反证条件、预期方向与原始调用位置。无可检验发现时须说明原因，不强制生成关系。
- 工具返回真实的历史样本数、缺失和配对变化统计。Critic 必须引用该调查的真实工具结果哈希，提出后续独立检验；保留、拒绝或数据不足都被归档。历史相关性不等于已验证预测能力。
- 复盘看到原始研究记录、预测、结算后的真实反馈，并引用实际反馈字段。没有经验可以解释具体缺口；空字符串或编造事实 ID 不算有效复盘。格式通过只表示可读取，文本结论仍需验证。

默认 Qwen3-8B-Base 单实例、全部权重冻结、无 LoRA、无梯度更新。当前是有固定预算的串行角色协作；尚未学习语义检索表示、开放任意工作流搜索或验证自主改进的泛化效果。复盘保持真实反馈可用时间，不倒填到更早的历史决策。

## 连续 $100 账户

`paper_trading.simulate(..., through=T)` 支持截至 T 的账户快照，保留既有完整回放的默认行为。团队能看到当时现金、预留资金、持仓、已发生费用和标记价格代理，未来结算不能提前改变这些值。

`team_portfolio.py` 将全部决策按时间放入同一个账本，保持单笔 $2、单事件 $5、总敞口 $20、默认费用率 1% 和成交价溢价 0.01 的既有约束。同一合约尚有敞口时不会因重复研究再次买入。研究频率不等于成交频率；可以一直持有现金。

复盘的交易贡献按实际连续账本中当前回合的订单 ID 归因；不会将独立重置账户中的虚拟盈利当成真实第二笔成交。全账户终值另行报告。费用已在账本扣除，不会再从目标进度中扣一次。

目标以回放结束、持仓完成结算后的现金是否达到 $110 计算，同时记录首次观察到无持仓、无预留资金且现金达到 $110 的时刻。短暂的浮盈或多个独立账户平均值不算目标达成。回撤仍是离散历史价格标记代理；成交是假设的下一笔合格历史成交，不保证盘口深度。当前退出方式仍是持有至结算，没有实现自主中途卖出。

## 配置与复现

- 目标：`configs/team_simulation_objective_v1.json`。
- 冻结实验：`configs/team_discovery_v2.json`。
- 数据：`data/processed/team_rsi_cohort_20260920_v2` 学习分区；旧开发事件不再作为新验证使用。
- 运行：`runs/qwen3_8b_team_discovery_frozen_100_to_110_v2`。

```bash
PYTHONPATH=src python -m foretellmesh.team_discovery_experiment run \
  --config configs/team_discovery_v2.json \
  --model-manifest runs/qwen3_8b_team_learning_interface_smoke_v1/model_manifest.json \
  --output runs/qwen3_8b_team_discovery_next

PYTHONPATH=runs/qwen3_8b_team_discovery_frozen_100_to_110_v2/source_snapshot \
python -m foretellmesh.team_discovery_experiment audit \
  --output runs/qwen3_8b_team_discovery_frozen_100_to_110_v2
```

本轮只测试探索、记录和连续模拟账户，不检验独立效果，不生成微调准入。完整原始调用、搜索结果、研究记录、失败、费用账本和目标进度归档；不能为了达到 10% 删除失败或扩大风险。

初次运行 v1 在 8 个完整回合后中断：模型返回严格的 `output.search` 包装，而解析器只接收裸参数，导致合法查询无法执行。v2 接受这个唯一明确包装，不抽取任意正文、不更改搜索参数；复盘提示同时列出实际允许的反馈字段。原始失败输出和源码保留，固定学习回合、成本与风险规则不变，未按盈亏选择重跑范围。
