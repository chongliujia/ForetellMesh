# 分步团队研究：关系、数据与计算一致性

日期：2026-09-21。上一轮冻结 Base 两次未能输出可执行方法，其中一次声明了参照合约，公式却完全没使用它。本轮将单次复杂请求拆开，保持研究内容由团队提出；不人工替换关系或修正成盈利规则。

## 已实现的工作流

在同一个冻结 Qwen3-8B-Base 上，由 LangGraph 串行安排：

1. **研究角色**提出关系、预测对象、期限与合约绑定。此时不要求写公式或判断效果。
2. **数据角色**只看选定关系与相关合约，列明需要的量、目标/参照角色、历史滞后，以及缺失的数据。不再接收整个目录。
3. **确定性工具**检查这些输入能否同时取得、来源是否在各自截止时间以内、是否满足三小时新鲜度。对于已明确声明的外部票房、发帖数等量，尚未接入时记为不支持，程序不替换为合约价格。模型是否正确识别了所需的量，仍是单独的语义问题。
4. **计算角色**只看选定关系、明确输入和覆盖汇总，生成表达式与预先确定的比较阈值。公式引用的角色和滞后必须与声明输入完全一致，不能遗漏参照合约或偷换数据。程序仅机械拼接各角色的输出。
5. **冻结与执行**先保存原始方法及前序调用哈希，再读取检验目标、计算误差。最后的审阅角色必须准确引用程序结论。

每个模型阶段最多一次格式/结构修复。失败、明确放弃、未支持的数据需求与零共同观测都会终止依赖步骤并保留原因；不会访问评分标签，也不会为了取得好分数更换合约重试。

## 检查能保证什么

角色分工与程序校验保证声明的数据、实际公式引用、合约绑定和评分协议一致；它们不能证明文字假设有合理机制，也不能证明公式忠实表达了所有自然语言含义。公式即使引用了参照变量，也可能没有实际预测价值，必须看后续数据检验。

数据可用性工具只接收历史输入接口，不接收结算标签或未来目标价格。因此 `ready_for_calculation` 仅表示至少一个预定日期能够取得全部输入，**不表示已经有足够的独立事件、可用预测标签或预测优势**。它也未用结算边界筛除日期；完整评分仍由既有执行器执行这些检查。可用性记录包括所有日期的输入来源与失败原因，下游计算角色只接收汇总。

沿用既有诊断的数据与评价边界：20 个已准入训练合约、固定日网格、最多 90 天、事件组内再组间平均的误差、至少三个目标事件组与 80% 覆盖的预筛。未来价格目标和最终事件概率分别评分。资料不足不能被解释为整个历史档案不足，多个同期合约也不等于多个独立事件。

本轮没有新增可用数据源或扩大合约集合，只改变团队交接方式。模型冻结，所有检验仍属于重复使用训练数据的研究诊断；不修改 $100 模拟账户，不据此微调或晋级策略，最终测试保持封存。

## 实际结果

运行目录：`runs/qwen3_8b_team_staged_method_v1`。模型完成两次调用，均通过格式校验，无修复调用。研究角色仍提出《蜘蛛侠：纵横宇宙》与《变形金刚：超能勇士崛起》的首周票房关系，选择目标合约 251132、参照合约 251306，预测一天后的 Yes 价格。数据角色声明两个合约的当前 Yes 价格，未报告任何缺失数据。

确定性工具检查 90 个预定输入采样日期，**共同可用观测为零**。失败明细：参照合约尚未初始化 15 次、没有报价 3 次、报价过旧 72 次；目标合约没有报价 1 次、报价过旧 84 次。每个日期可能有多个失败原因，不能将这些计数相加解释为日期总数。这只是输入预检查，包含尚未按目标结算边界过滤的日期；更不代表这两个合约完全没有原始成交。

流程以 `no_joint_observations` 停止，没有调用计算角色、冻结交易方法或读取检验目标进行评分。**零个真实预测评分，不是预测误差为零。** 此次检验不改变交易账户，不产生新的盈亏结果。

仍然存在语义问题：假设谈票房收入，数据角色却将需求声明为合约价格。结构校验并未识别或证明这个映射正确；本次阻止执行的实际原因是没有共同输入，而不是成功核验了变量含义。下一步优先让研究角色显式声明变量身份及单位，再要求数据角色逐项绑定到确切来源，不能把不同量当成同一个输入。

新增十项分步流程测试，连同原有相关模块共 **142 项测试通过**。测试覆盖完整合成研究链、未来数据拒绝、未支持的外部量、无共同历史、公式遗漏/更换输入、冻结先于标签访问、阶段失败传播与逐调用回放。合成测试通过只表示这些程序行为正确，不能当作真实市场的效果证据。
