# PMA FOMC 研究数据集首版

后续已扩为[159 条观察的宏观研究数据集](pma_macro_research_dataset.md)，加入 CPI 与就业；本页保留原始 84 条 FOMC 发布的统计。新版本逐条保留本版样本的输入、标签与分区。

2026-09-19，从固定版本 PMA Polymarket 历史库构建了本项目自己的小型研究数据集：**84 条历史观察、42 个合约、10 次 FOMC 会议**。训练、验证、测试按会议时间冻结，输入与标签分开导出。这是可复现的数据发布，还没有进行真实事件模型评测或训练。

## 范围和覆盖

本轮在此前 [16 合约补证试跑](pma_proof_pilot.md)的基础上，扩至同一套已审核适配器覆盖的 16 次会议、69 个原生合约。每个合约固定官方声明前 7 天、前 1 天两个观察点；选择不依据最终结果、报价是否可用或预测分数。上游来源、完整价格库、合约源码、捕获响应和处理代码均有哈希绑定。

| 检查 | 数量 |
| --- | ---: |
| 计划会议 / 合约 / 观察 | 16 / 69 / 138 |
| 完整采集链上证明的合约 | 68 |
| 规则、最终结算及官方结果核验通过的合约 | 50 |
| 同时通过事前证据和历史价格检查的观察 | 88 |
| 用途审阅后实际发布的观察 | 84 |
| 排除账本保留的观察 | 54 |
| 实际发布的合约 / 会议 | 42 / 10 |

合并此前试跑，共归档 123 次 HTTP、4,687 次只读 RPC 响应，HTTP 状态均为 200。返回成功不代表证明有效：合约 `553813` 的 API 定位交易没有匹配的初始化日志，保留采集不完整状态，两个观察均不发布。

18 个合约的当前标题或规则正文与链上初始化文本不一致，涉及 36 条观察，继续隔离。20 个预设观察点没有三小时内的有效历史成交报价。2026 年一月整组 8 条观察因基准关联/既有保留用途排除。原因之间有重叠，不能相加当作排除总数。

本版保留部分合约合格的会议，因此同一会议的所有概率档位不一定齐全；不能直接用这些行构建完整的多分类概率分布。每组的计划数、发布数与覆盖率见 `event_groups.jsonl`，全部 138 个计划观察均能在发布清单或排除账本中找到。

## 固定分区与基准隔离

| 分区 | 实际合格会议 | 合约 | 观察 | 用途 |
| --- | --- | ---: | ---: | --- |
| train | 2024 年六月、七月、十一月、十二月 | 19 | 38 | 小规模结果监督 / RL 原型 |
| validation | 2025 年五月、六月、七月 | 12 | 24 | 开发诊断 |
| test | 2025 年九月、十月、十二月 | 11 | 22 | 保留测试，禁止训练与调参 |

分区边界预先固定为官方发布时间早于 2025-01-01、2025-08-01、2026-02-01 UTC。排除后没有重新移动边界来填补数据。同一会议的所有合约和观察点只属于一个分区；前一分区的全部链上结算时间必须早于后续分区最早观察点。

`membership.jsonl` 用 `sample_id` 保留 split、event_id、event_group_id 和 dataset_version；记录文件继续使用项目既有严格 schema，避免改变训练和评估接口。时间检查采用公开链上结算时间，不表示本地训练在那个历史时点实际发生。

[范围审阅](../configs/pma_fomc_scope_review_v1.json)绑定全部 69 个候选的原生身份、题目、规则和 token 映射，以及固定 ForecastBench 索引的 2,244 条记录。审阅覆盖 250 个原生问题模板、250 个时间序列模板；精确身份命中始终优先排除整组，不以“无字符串匹配”自动认定无语义重叠。该审阅由助手完成，并非独立人工认证。

2026 年一月与 ForecastBench 同期利率任务存在关联，整组保留，不能因旧数据在时间上较早而自动加入训练。2024/2025 单次会议没有发现索引中的同次发布目标；不同会议仍共享宏观驱动，不声称统计独立。全部未选父事件，包括年度累计、跨会议组合和任命/提及类合约，均不获本次发布授权；`market_scope.jsonl` 保留 906 个候选的用途范围。

既有 2026 年双平台评测范围和保留样本的用途没有改变。本版 **10 个不同会议、单一平台**，尚不满足现有正式 Agent 对照要求的 20 个事件组、双平台数据和冻结模型运行配置；正式评分准入仍为 false。

## 数据检查与解析修复

证明流程沿用 [补证试跑的规则与结算审核](pma_proof_pilot.md)：初始化文本、创建者更新数组、已审阅 runtime、UMA 报告、NegRisk 身份映射、最终 CTF 赔付及区块时间必须相符，再与对应官方声明交叉核对。信任范围仍是区块浏览器源码验证和单一公开 RPC 的历史响应，不是独立共识证明。

本轮修复了两类实际解析问题：

- 官方声明可能同时列出委员会决议和反对者建议，不能因为文中有两个利率区间就混淆结果。解析明确的委员会决议，拒绝重复或未知形式；支持混合分数中的不换行连字符，不跨句寻找利率。
- 初始化文本末尾存在三种已观察到的分隔格式：`, res_data:`、` res_data:`、` market_id: <原生 ID> res_data:`。严格比较完整标题和规则正文，有 market ID 时必须一致。正文差异、额外修改或错误身份仍拒绝。

旧题目语法覆盖实际审阅的月份、年份与 25bp 档位。2024 年十一月、十二月的显式“其他档位”合约只在 25bp 网格上核对；非网格变动不自动套用规则。

每条模型输入仅含当时规则、观察时间、上次 FOMC 官方声明和截止时点前的历史成交价。没有把当次官方结果、最终价格、结果标签或后来的新闻传给模型。官方历史页面依赖来源对发布日期和修订状态的声明；本地采集时间另行保留，不冒充当时保存的网页快照。价格仍是最新有效区块内平均成交价，不能解释为可执行报价。

## 用途与当前局限

这批数据具有二元结果标签，可用于结果监督研究或已具备任务能力的模型的 RL 原型；**没有把最终输赢改写为 SFT 的 0/1 概率答案**。真实 SFT 教师目标尚未生成，也没有自动启动训练。训练仅 4 个会议，规模不足以支持可靠的参数调优结论。

开发诊断只计算 train/validation 的确定性基线，不计算 test 分数。观察加权的市场 Brier 分别为 **0.001593 / 0.000646**，0.5 基线为 0.25；事件等权 Brier 另行记录。这表明该小样本接近发布时已较容易预测，不是模型取得了这些成绩，也不能外推整个预测市场。ECE 仅作描述，同一会议的多个档位、两个时点不能视为独立样本。

证据目前仅有上次声明，尚需补充有历史时间证明的通胀、就业和其他事前信息。历史结果也可能存在于基础模型预训练语料，因此本版属于回顾性研究集，不能替代前瞻性评测。下一步优先扩充 CPI、就业等事件及证据覆盖，再冻结真实模型对照实验；不通过增加同一会议的重复行来凑事件数。
