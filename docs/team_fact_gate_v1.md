# 逐笔经验的事实核验与方法准入

日期：2026-09-21。保持 Qwen3-8B-Base 与适配器冻结，不训练、不自动晋级。前一轮的九笔复盘虽全部格式合格，却把两笔亏损称为盈利；旧实现仅以格式、时间和哈希检查决定是否把复盘放入在线记忆。本轮修复这个缺口，原实验与失败输出全部保留。

## 新的准入流程

每笔已结束交易仍进入经验库，不按盈亏筛选；未平仓继续保留过程。进入指导后续决策的记忆，则需要额外检查：

1. **程序提供事实。** 由成交与结算账本计算持仓方向、成本、双边费用、兑付/卖出收入、净盈亏和持仓时间，核对账本恒等式。事件概率明确指最终 Yes，而不是价格上涨；提前卖出不能提前计算事件 Brier。
2. **团队提出解释和实验。** 必须正确识别方向、盈亏、退出方式与预测对象，并引用存在的事实编号。允许不提出新规则；若提出改动，需说明可观察的适用条件、具体改变、反证，以及基线、干预、指标、通过条件和事件组隔离的验证方案。
3. **批评角色单独检查。** 检查事实矛盾、证据不足、因果归因过度、模糊改变，以及把单次胜负当作反证等问题。不把错误答案改写成正确答案；失败、否决和无经验输出照常归档。
4. **准入只允许探索。** 只有非空候选方法、确定字段校验通过、批评检查全通过且没有未解决问题，才可进入训练阶段的探索记忆。每次读取记忆重新验证事实、时间、哈希和批评结果；旧版未经核验的复盘不再自动进入记忆。

确定字段和账目恒等式由程序严格检查；自然语言解释的审查仍由同一个冻结 Base 的另一个角色完成，可能漏判，不能称为独立真值裁判。`eligible_for_exploration` 不等于盈利有效、因果正确或可用于微调。

当前在线决策记忆使用单独的、带来源哈希的方法视图：包含程序核验的事实与候选方法，**不包含模型自由撰写的 assessment**。完整解释仍保存在逐笔档案中供复核。这个额外隔离由单元测试和逐调用重放测试覆盖；本轮 GPU 对照使用冻结的离线方法记忆，本来也不注入原复盘 assessment。

研究方法的内容由团队提出，没有预设 RSI 指标、股票因子或固定止盈止损。指标列表只约束实验怎样被评价，不限制团队探索哪种合约关系。

## 固定的对照协议

配置：`configs/team_fact_gate_v1.json`。输入仍是原 $106.523346 账户全部九笔成交，两笔盈利、七笔亏损；按原顺序逐笔生成新复盘和批评记录。同时让批评角色检查上一轮九条旧复盘，保留其判断和失败，不以人工结论替换模型输出。

若有方法通过准入，按入场时间取最早至多三条，冻结为可核验的离线方法记忆。完整经验和所有未选入的方法保留，不按收益排序。记录实际生成时间、标签捕获时间、训练来源事件的最晚公开结算时间，以及原研究目录的全部事件组。离线拟合于当前时间，不能声称这些记忆在历史上已经存在。

然后在既有记忆实验开发队列中按时间取第一个作业，对照无方法记忆的团队与带准入记忆的团队。两组各自使用连续 $100 模拟账户，相同数据源、费用、风险限制、冻结 Base 和开始/结束边界，最多四次自主复核、十四天观察。模型各自决定复核时间，使用实测生成延迟；它们的后续观察时间可能不同，不能称为完全相同时点的概率配对。复核不强制交易，窗口结束不强制平仓，残余仓位另报停止复核后的结算诊断。

两个团队在对照期间均冻结记忆、不从该窗口反馈中学习；新候选来源与整个诊断检索目录的事件组隔离，并且来源事件先于诊断观察。**这些开发事件以前已经使用，本轮只是机制和行为诊断，不是新的独立效果验证。** 如果没有方法通过准入，记录原因并跳过没有实际干预的账户对照，不人为制造一个方法。

新的独立事件验证仍是认定改善和考虑微调的必要条件；本轮不会因格式改善、现金不变或一个账户盈利而满足该条件。已有最终测试保持封存。

**预算限制影响解释。** 两组都用完四次复核：对照组的复核跨约 26 小时，记忆组跨约 3 小时。此后模拟继续处理已存在订单和结算，不再调用团队。十四天是账务观察边界，不是团队完整地连续管理十四天；因此不能据此断言记忆导致持续管理表现变差。这里只对同一已用开发事件做有限预算的行为诊断。

**批评角色未解决语义可靠性。** 对旧九条复盘，它全部判为事实一致，漏掉了合约 254462、504409 把亏损称为盈利的已知错误。旧记录仍被新的程序准入规则阻止，但不能把这个拦截归功于模型批评。唯一新候选只提出“交易前验证相关性的预测效果”，没有明确可执行的验证操作；其反证仍可能把单笔亏损当作关系无效。批评角色却通过了它，说明同一 Base 的角色互评不足以证明经验正确。

本轮结论是**不晋级、不微调**，保留全部结果供下一轮改进。下一步优先让团队将候选方法写成能够调用工具执行的干预与检验，并积累带时间戳的证据，再进入新的事件组验证；方法内容仍由团队自主提出。程序核验账目、自由解释不进入决策记忆，是已落实的防错措施，不代表自然语言候选已经可靠。
