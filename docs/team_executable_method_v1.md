# 团队提出方法，工具执行检验

日期：2026-09-21。承接上一轮事实准入诊断：一个候选仍只提出“先验证相关性的预测效果”，没有可执行的计算或实验。新增可选研究流程，把方法从文字建议变成可重放的工具请求；不更换模型、不训练、不改写旧收益实验。

## 工作流与边界

LangGraph 串行编排同一个冻结 Qwen3-8B-Base 的方法规划角色与实验审阅角色，中间由程序完成检验：

1. 规划角色接收既有探索候选、训练分区的完整合约规则、初始化时间和历史价格覆盖数。它自主选择合约、关系、计算表达式、预测期限、最少样本数和所需改善幅度；也可明确报告无法表达或缺少数据。
2. 将原始方法和模型调用记录冻结，再读取检验目标。最多一次结构修复，没有看到分数后重试至成功的循环。
3. 工具按不可变计划构造事前特征、计算预测、读取之后的价格或可用结算标签、比较基线，输出每个观测的来源时间、错误与分数。
4. 审阅角色可以解释局限，但必须逐字段正确引用工具的结果哈希、状态和是否达到后续独立验证的预筛条件。它不能凭自己的判断改写数值结论。其自由解释仍不是已核验事实。

表达式使用价格读取 `p('target', N)`、`p('peer', N)` 与加减乘除、绝对值、最小值、最大值。N 是过去 0–30 天的整数滞后。安全解释器逐节点计算，不调用 Python `eval`/`exec`，不允许外部代码、属性访问、任意函数或未来特征。表达式可以组合跨合约价格和滞后变化，不预设动量、均值回归、宏观类别或固定相关关系。

这是目前已接通的工具能力范围，**不是假设潜在关系只能来自价格**。规则文本可用于提出合约关系，但解释器暂不能验证自然语言逻辑，也没有历史新闻、发帖计数、外部资产价格等变量；相关假设需要另接可追溯数据工具。不得用生成文本补齐这些事实。

## 两类目标分别评价

| 目标 | 标签 | 基线 | 指标 |
| --- | --- | --- | --- |
| `future_yes_price` | 之后 1–14 天的有效 Yes 成交价格 | 当前 Yes 成交价格不变 | 价格均方误差 |
| `resolves_yes` | 有可用时间证明的最终 0/1 结算 | 当前 Yes 市场价格 | Brier |

未来价格预测不是最终事件概率，任何一类评分改善都不等于净盈利。本轮不下模拟交易指令，也不修改原 $100 账户；交易费用、成交可行性和连续账户净值需要在后续独立模拟中另行验证。

采样采用从合约初始化之后开始的固定 UTC 日网格，最多 90 天；未来价格窗口按预测期限错开，避免同一目标的窗口重叠。结算目标每个合约只取一次预定观测，不反复用同一个结算结果冒充更多样本。对缺失或过旧的价格、初始化之前的特征、分母为零、越界预测逐项记录失败，不补零、不强制裁剪、不寻找下一个更有利的日期。

误差先在事件组内平均，再对事件组等权平均。价格目标至少八个有效观测、结算目标至少三个；两者均要求至少三个目标事件组、80% 有效覆盖，再检查团队预先提出的改善阈值。**这些是研究预筛条件，不是统计显著性或泛化保证**；不同组也可能共用同一参照合约。所有样本、缺失和失败照常保留。

第二版模型提出用《蜘蛛侠：纵横宇宙》与《变形金刚：超能勇士崛起》的首周票房关系预测合约价格，却写出只依赖目标合约自身价格的表达式：`p('target',0) + (p('target',0) - p('target',1)) * 0.5`。它声明的参照合约 251306 没有被使用；而且实际工具输入是合约成交价，并非电影票房数据。参照合约在 2023-06-06 00:58:41 UTC 初始化，目标合约在同日 03:16:31 UTC 结算，共同存续仅约两小时十八分；固定 UTC 日网格没有二者同时存续的采样点。程序没有擅自删掉参照合约、换公式或将此计划变成成功样本。

第一版放弃计划时声称数据不支持；这是模型原话，**不能据此断言整个历史数据集不足**。当前诊断范围只有已准入训练分区的 20 个合约，而且价格覆盖数受固定采样时间与三小时新鲜度限制。零有效日采样不代表整个合约从未交易。

本轮具体定位到“假设 → 所需数据 → 计算表达式”的一致性失败。下一步应把关系设计、数据选择和公式构造拆成更小的团队协作步骤，每一步由工具校验；仍由团队提出关系，不由人工替换成固定交易策略。目前没有候选满足进入新事件组验证的前置条件，未打开新开发事件或最终测试，未微调，未修改交易账户。
