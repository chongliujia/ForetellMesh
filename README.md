# ForetellMesh

面向预测市场的多 Agent 研究与**自动模拟交易**系统。以 **100 美元虚拟本金**完成分析、决策、风控、模拟成交与账户记账，用计入成本后的净收益和回撤验证系统价值。基础模型为 **Qwen/Qwen3-8B-Base**，本地硬件为 RTX 3090 24GB。

当前阶段：**已完成原始 Base + LangGraph 离线模拟，正在冻结 8B 的前提下检验小型交易决策 RL**。预测 Brier / 校准仍用于诊断；SFT、LoRA、RL 是可选改进手段。首版流程和运行命令见 [100 美元 Base 模拟交易](docs/offline_paper_trading.md)。

最新交易目标已按用户要求改为：**最大化扣费后的净收益，取消每 7 天必须成交，允许长期空仓**。当前入口为[多 Agent 分析接入交易策略](docs/allocation_multi_agent.md)，沿用[费用变量与净收益 PPO](docs/allocation_profit_fee.md)的成本和风险规则，并用持有 $100 现金作对照。以下涉及强制周频的结果均属此前协议，保留用于复现，不再是新策略的活动要求。

已将 **Research → 量化 → 博弈论 → Forecast** 的真实 8B 输出接入交易 RL：84 份历史分析中 79 份有效，实际调用模型 348 次；三组各三个配对种子、九次训练、84 组训练内回放。主成本平均期末资金为价格特征 **$87.48**、历史价格参考 **$87.01**、多 Agent **$91.19**、现金 **$100**。多 Agent 使三个种子均比价格对照少亏，但仍未盈利；79 份有效预测概率几乎都复制市场价格。简单的平价正费用环境中六个策略均学会空仓，不能将真实市场失败简单归因于 PPO 完全学不会等待。8B 与 LoRA 未更新，最终测试仍封存；[配置、实测结果与局限](docs/allocation_multi_agent.md)。

本轮最终 49 项回归测试、84 组独立复算通过，另核对 393,204 个决策点和 20,170 笔成交手续费。收益改善主要来自减少价格加减价损耗，尚未显示原始价格选单优势；候选策略不晋级默认。

此前纯价格费用协议已完成 **六次训练、66 组训练内回放**：主成本下，三个种子平均期末资金为固定费率重训 **$88.02**、多费率重训 **$88.83**、关闭周频的旧策略 **$90.02**，持有现金 **$100**。方法修改已生效，但该轮没有训练出超过现金或旧策略的候选；61 项相关测试、66 组逐笔复算及费用核对通过，checkpoint 不晋级。8B、LoRA 未变，最终测试仍封存。

首轮离线模拟已完成：**91 条验证观测、55 个合约、13 次宏观发布，Base 输出全部有效，100 美元账户期末仍为 100 美元、零成交**。当前预测几乎复制市场价格，未形成满足成本后优势阈值的信号；固定训练基率对照在主成本假设下成交 15 笔，期末为 78.96 美元。原始响应和全部账本复算通过，峰值分配显存 15.62 GiB。本轮不加载 LoRA、不训练，收益结果是历史成交价假设下的开发集模拟，尚未证明盈利能力；[实测结果与复现](docs/offline_paper_trading.md)。

已加入可选的 [量化专家与博弈论 Agent](docs/market_expert_agents.md)，共享原始 Base，并完成 **13 个验证事件组、四组共 52 条流程**对照：有效数为 13 / 12 / 13 / 12，三种成本场景下各账户均保持 $100、零成交。博弈论组一条 45% → 55% 的信号因缺少决策后成交记录而取消；共同 12 条样本上 Brier 从 0.166915 升至 0.175248，未显示改善。新增角色保持可选，不设为默认；本轮约 20 分钟、峰值分配显存 15.85 GiB，原始响应、特征与账本重放通过，未启动训练。

已加入 [均值回归与每 7 天成交约束](docs/mean_reversion_weekly.md)，并对同一批 55 个验证合约完成按小时的独立价格策略模拟。v2 主成本情景中，**仅均值回归期末 $98.92；均值回归 + 周频参与期末 $90.35，32 次买入、32 次卖出，最长成交间隔 6.96 天**。无成本参照下组合期末 $100.83，尚无覆盖成本后的盈利证据；强制周频参与贡献了约 $8.58 的损失。三档成本情景的组合均满足周频要求，首版因价格准入限制未达标的记录也保留。本轮为 CPU 确定性回放，无模型调用或训练；两版全部特征、账本和周频指标复算通过。

已完成 [交易决策层 PPO 原型](docs/allocation_ppo.md)：修正周频尾部选单及非正模拟卖价处理，冻结 8B，用训练分区 25 个合约、6 个事件组训练三个 **21,402 参数**的小策略，各 32,768 步。主成本验证中，三个 PPO 账户期末为 **$97.60 / $96.22 / $95.76**，相对各自初始化策略少亏，但均未满足每 7 天实际成交；相同环境的固定均值回归对照期末 $96.43、周频达标。24 组成本/策略回放已从冻结权重复算通过，PPO 不晋级默认。训练约 83 秒、全流程约 168 秒，仅 CPU；未训练 Qwen/LoRA，最终测试仍封存。

## 快速运行

要求 Python 3.11 或更高版本。在仓库根目录运行：

```bash
PYTHONPATH=src python -m foretellmesh evaluate \
  --data examples/synthetic_forecasts.jsonl \
  --config configs/synthetic_baselines_v1.json \
  --output runs/synthetic_baselines_v1
```

输出目录必须不存在；重复运行请使用新目录，以保留已有实验结果。

也可以安装到自己的开发环境后使用 `foretellmesh evaluate` 命令：

```bash
python -m pip install -e .
```

**示例中的 17 条记录全部为人工构造，分数不代表模型能力或真实预测表现。** 示例故意包含跨时间边界的事件、延迟公布标签、重复记录和未结算事件；预期保留 train / validation / test 各 3 / 2 / 3 条，剔除 9 条。

## 生成的文件

| 文件 | 用途 |
| --- | --- |
| `report.md` | 可阅读的基线分数、覆盖率、市场同样本比较和剔除统计 |
| `report.json` | 完整指标、校准曲线数据、数据与代码哈希、数据源版本和实验参数 |
| `predictions.jsonl` | 验证集与测试集的逐样本预测和评估标签；仅供评估使用 |
| `split_manifest.json` | 每条样本的最终分组，或剔除原因 |
| `config.json` | 本次运行的原始配置副本 |

默认三条基线分别为固定 `0.5`、仅在训练集拟合的经验基准概率、观测时刻可用的市场概率。配置可显式选择 `baselines`；仅评估保留集时使用 `["constant_0_5", "market"]`，不拟合经验概率，也不要求把基准数据放进训练集。省略该选项时行为保持不变。

评估包含 Brier Score、Log Loss、固定等宽分箱的 ECE、校准曲线数据和覆盖率。市场价格缺失时，额外在有市场价格的同一批样本上计算全部基线，报告 `baseline - market` 的差值；负值表示该项分数更低。无可评分样本时返回 `null`，不伪造零分。

## 数据约束

- 每条证据必须满足 `published_at <= available_at <= observation_time`；市场快照遵守同样的可用时间约束。未知时间、未来证据、非法概率或不一致身份会使整次运行失败。
- 结算标签独立保存。模型输入只允许通过 `ForecastInput.to_payload()` 构造，不包含标签、结算时间、数据源身份或切分信息。
- 时间切分由配置固定。跨越 train / validation / test 边界的事件组整体剔除，避免相同或高度相关事件跨集合。
- `eval_only` 数据源所在的事件组不能进入训练集。跨数据源的等价事件必须使用统一 `event_group_id`。
- 规范化后完全相同的问题必须属于同一事件组；相同问题与观测时间的副本只计一次，优先保留 `eval_only` 来源。
- 训练标签须在验证开始时可用，验证标签须在测试开始时可用，测试标签须在评估截止时可用。缺失或延迟标签会被记录并剔除。

完整字段、切分边界、分数定义和局限见 [数据与评估契约](docs/data_contract.md)。时间校验检查的是已声明元数据；它无法证明来源内容从未修改，也不会自动完成语义去重。真实基准报告前仍需审核历史内容快照和事件分组。

## 真实数据导入

数据源版本和文件 SHA-256 已登记在 [来源配置](configs/data_sources_v1.json)。以下命令从上游固定 revision 下载约 9 MB 的 Prophet CSV 及其数据卡，不执行上游脚本：

```bash
PYTHONPATH=src python -m foretellmesh fetch \
  --source prophet_arena --output data/raw/prophet_arena_v1

PYTHONPATH=src python -m foretellmesh ingest \
  --source prophet_arena \
  --data data/raw/prophet_arena_v1/subset_data_1200.csv \
  --output runs/prophet_source_audit
```

ForecastBench 目前固定一个轮次用于**格式接入审计**，不是已批准的最终评估集：

```bash
PYTHONPATH=src python -m foretellmesh fetch \
  --source forecastbench --output data/raw/forecastbench_v1

PYTHONPATH=src python -m foretellmesh ingest \
  --source forecastbench \
  --data data/raw/forecastbench_v1/2026-01-04-llm.json \
  --resolutions data/raw/forecastbench_v1/2026-01-04_resolution_set.json \
  --output runs/forecastbench_source_audit
```

`ingest` 默认生成审计、候选数据、逐样本状态与时间证明模板。未补齐元数据时，`records.jsonl` 为空；这是预期的隔离行为，不是成功完成真实基准评估。只有附带可追溯时间证明、通过事件分组和标签检查的记录才会写入 `records.jsonl`。

来源核查结果、PMA 的支持范围，以及 `--annotations` 用法见 [真实数据接入说明](docs/source_ingestion.md)。标准库测试无需联网；Parquet 适配与相应测试需要可选依赖 `python -m pip install -e '.[parquet]'`。
